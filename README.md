# CM500292_DatabasesCoursework

### Version
Python 3.11+

### Dependencies

* SQLite3
* sqlparse

### Install Dependencies

```
pip install -r requirements.txt
```

### Run

```
python main.py
```

On first execution the application will:

1. Create the database schema.
2. Populate sample data.
3. Display the main menu.

## Functionalities

```
1. Add a New Flight
2. Search Flights
3. Update Flight Schedule
4. View Pilot Schedule
5. Assign Pilot to Flight
6. Exit
```
